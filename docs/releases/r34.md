# Baiakeros client update r34

Production updater revision 34 packages the Windows Release executable and all
runtime files under `data/`, `mods/` and `modules/`. It includes server-authoritative
Cavebot time/XP, Distance recovery and safe movement, window restoration,
asynchronous route dialogs, Forge cost corrections and quiet Spells notifications.
Party Hunt sources are preserved, but its tab and module scripts are disabled.

The upload directory is `D:\otserv\site-update`. Upload its contents directly
to `/downloads/client/`: `packages/` first, launcher and its SHA-256 next,
then `assets.windows.json` and `client.windows.json` last. Do not delete older
packages from the live site during uploads; older clients can still request them.
The local preparation folder contains only the current update.

All 16,307 LZMA files were decompressed by the packager and their hashes checked.
The runtime executable SHA-256 is
`31cf2fe982a6a5e398abd026d37b72ad2d48e9b3c124a7028e71b4311e701992`.

Local validation: Windows `windows-release` preset; eight client Lua regressions;
21 server Forge integration tests in an isolated disposable test database;
server Party Hunt and Stellar Forge Lua tests; Wiki PHP syntax checks.
GitHub Actions could not start because the account billing/spending limit blocks
jobs. The legacy Auto Explorer test requires updated mocks before it can run.

Generation uses `tools/build_client_update.py` with `--revision 34`, the built
`build/windows-release/bin/otclient.exe` and production `environment.production.lua`.
Reports and the previous r33 payload are kept outside the upload directory.
